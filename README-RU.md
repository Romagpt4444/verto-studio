# Verto Studio — портфолио

Обновлённая версия существующего сайта Verto Studio с тремя демонстрационными проектами:

- Morrow Coffee;
- APEX Detailing;
- FORMA ESTATE.

## Как открыть

1. Откройте папку `Verto-Studio-Portfolio` в VS Code.
2. Откройте `index.html` через Live Server (`Go Live`).
3. Проверьте раздел «Портфолио», раскрывающиеся описания и форму в разделе «Контакты».

## Ссылка APEX Detailing

Сейчас кнопка открывает рабочую локальную версию из `projects/apex-detailing/index.html`.

После публикации APEX замените **два одинаковых адреса** в `index.html`:

```html
./projects/apex-detailing/index.html
```

на полный публичный URL. Рядом с нужным местом оставлен комментарий `APEX_URL`.

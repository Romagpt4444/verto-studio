# Verto Studio — полёт

Статический сайт с одной непрерывной главной сценой. Прокрутка меняет рассвет, облака, атмосферу и космос, пока HTML-главы рассказывают об услугах, проектах и Lead Agent. Камера показывает корпус ракеты от первого лица. Контент и ссылки остаются доступным семантическим HTML.

## Локальная работа

```bash
python3 -m http.server 8000
python3 scripts/site_qa.py
node --check scene.js
node --check script.js
```

Открывайте сайт через `http://localhost:8000/`, а не через `file://`. Сборка и внешние зависимости не требуются: `scene.js` — исходный код WebGL-сцены, `experience.css` — оформление главной, `main.css` — общие стили. Текстуры хранятся в `assets/rocket-sequence/web/` и принадлежат этому проекту. Старые файлы сборки Three.js удалены, чтобы случайный `npm run build` не перезаписал новую сцену.

## Доступность и производительность

Сцена декоративна и не блокирует интерфейс. Если WebGL недоступен, используется статичный фон. При `prefers-reduced-motion` отключено движение и переходы. На телефонах есть отдельный стартовый кадр; DPR ограничен до 1.25, на больших экранах — до 1.75. Кадры рисуются только после изменения прокрутки или размера экрана.

## Публикация

Домен `vertostudio.ru` привязан к GitHub Pages репозитория `Romagpt4444/verto-studio`, ветка `main`, корень. Файл `CNAME` содержит домен. DNS менять не нужно. Обновление production требует слияния изменений в `main` этого репозитория.

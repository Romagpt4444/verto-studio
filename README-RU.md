# Verto Studio — production-сайт

Статический сайт Verto Studio, отдельная страница услуг и три демонстрационных проекта:

- Morrow Coffee;
- APEX Detailing;
- FORMA ESTATE.

Основные файлы сайта: `index.html`, `services.html`, `main.css` и `script.js`.
CTA используют Telegram start-параметры `order`, `audit`, `redesign` и
`contact`, чтобы бот мог определить сценарий входа.

## Локальный запуск

Запускайте сайт через локальный HTTP-сервер, а не через `file://`:

```bash
python3 -m http.server 8000
```

После запуска откройте `http://localhost:8000/`.

## Публикация

GitHub Pages публикует ветку `main` из корня репозитория. Файл `CNAME` должен
содержать только `vertostudio.ru`. Все изображения и стили хранятся локально,
поэтому проект не зависит от временных внешних URL.

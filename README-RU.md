# Verto Studio — космическое путешествие

Статический сайт Verto Studio с интерактивной Three.js-сценой на главной странице. Камера находится на большой ракете; положение камеры, Земли, облаков, звёзд, спутника Lead Agent и точки назначения вычисляется из положения прокрутки. Основной текст, проекты и ссылки остаются семантическим HTML.

## Разработка

```bash
npm ci
npm run build
npm run check
python3 -m http.server 8123
```

`scene-src.js` — исходный код WebGL-сцены. `scene.js` — собранный файл для публикации GitHub Pages из корня ветки. `home.css` содержит оформление главной страницы. Остальные страницы и материалы проектов сохраняются как статические файлы. Внешних моделей и текстур в 3D-сцене нет; геометрия создана в коде.

Для полной проверки браузеров:

```bash
npx playwright install chromium webkit
QA_OUT=../qa-screens node scripts/browser_qa.mjs
```

## Доступность и производительность

Сцена декоративна и не блокирует ссылки. Если WebGL недоступен, используется статичный фон и весь HTML-контент. При `prefers-reduced-motion` остановлены непрерывная вибрация и движение. DPR ограничен до 1.25 на телефонах и 1.75 на крупных экранах; звёзды собраны в один `Points`, а невидимые объекты скрываются.

## Публикация

Действующий домен `vertostudio.ru` привязан к GitHub Pages репозитория `Romagpt4444/verto-studio`, ветка `main`, корень. Файл `CNAME` содержит домен. Текущий авторизованный аккаунт может публиковать код в своём форке `markchatgpt111-cyber/verto-studio`, но не имеет права записи в репозиторий владельца домена. Для обновления production требуется принятие PR владельцем исходного репозитория или предоставление права записи. DNS менять не нужно.

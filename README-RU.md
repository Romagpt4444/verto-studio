# Verto Studio

Статический сайт студии: главная, проекты, услуги, студия, Lead Agent, два кейса, семь демонстрационных сайтов и юридические страницы. HTML, локальный CSS и JavaScript; сборка и установка зависимостей не требуются.

## Локальная работа

```bash
python3 -m http.server 8000
python3 scripts/site_qa.py
node --check script.js
```

Главная использует оригинальное восьмисекундное видео металлической ленты и двенадцатисекундный видеорил существующих работ. Исходные изображения сохранены; WebP — производные для веба. Шрифт Golos хранится локально, лицензия — `assets/fonts/OFL.txt`.

Видео ленты загружается только при разрешённом движении. При уменьшении движения или экономии трафика используется постер; пользователь может включить видео сам. Есть пауза и остановка при уходе со страницы или за пределы видимости. Видеорил загружается по нажатию, использует нативные элементы управления, не содержит звука.

Меню поддерживает Escape, фокус и блокировку скрытых ссылок. FAQ использует нативный `details`. Выбор задачи формирует черновик по ссылке в Telegram; сообщения автоматически не отправляются. На сайте студии нет формы сбора данных, аналитики и серверных секретов. Формы в концепциях демонстрационные.

## Публикация

Production: `https://vertostudio.ru/`, GitHub Pages репозитория `Romagpt4444/verto-studio`, ветка `main`, корень. CNAME и DNS сохраняются. Публикация — обычное слияние проверенной ветки в main; откат — revert коммита обновления. Зеркало `markchatgpt111-cyber/verto-studio` не управляет действующим доменом.

`scene.js` и `experience.css` — совместимые заглушки от предыдущей концепции. Ракетные изображения сохранены как архивные исходники и не загружаются новым сайтом.

## Браузерная проверка и исходник видео

`scripts/browser_qa.cjs` — проверка всех страниц и восьми ширин, меню, фильтров, FAQ, рила, черновика обращения и статичного fallback. Требует доступного Playwright и Chrome; пакеты не добавлены в production. `PLAYWRIGHT_MODULE` позволяет указать существующий модуль. `QA_BASE` задаёт URL, `QA_OUTPUT` — каталог отчётов вне репозитория, `QA_ROUTES` — JSON-массив для повторной проверки отдельных страниц.

`scripts/generate_motion.cjs` сохраняет исходную процедуру создания обоих видео через Canvas и MediaRecorder. Запускается при работающем локальном сервере; использует исключительно изображения проекта, не требует внешнего API.

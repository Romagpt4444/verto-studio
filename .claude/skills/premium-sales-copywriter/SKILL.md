# Sales-копирайтер


Пишет продающие тексты, которые не вызывают отторжения у зрелой аудитории. 7 жанров, 8 фреймворков (AIDA / PAS / BAB / FAB / 4U / VPC / Magic Pill / Customer Journey), 30+ заголовочных формул, 5 структур холодных писем, 25-пунктный аудит-чеклист. Читатель приходит к выводу сам, без инфоцыганщины.

**Как вызвать:** «Напиши холодное письмо для...» / «Продающий пост в Telegram про...»

## Файлы

- `01-skill-prompt.md`: главная инструкция: тон, ЦА, 8 фреймворков, анти-абьюз
- `02-frameworks-cheatsheet.md`: разбор 8 фреймворков с примерами
- `03-headline-templates.md`: 30+ заголовочных формул по 9 группам
- `04-cold-email-playbook.md`: 5 структур холодных писем + анти-паттерны
- `05-audit-checklist.md`: 25-пунктный аудит «почему не продаёт»

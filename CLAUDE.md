# Verto Studio — правила для агента

Сайт https://vertostudio.ru/ (GitHub Pages, репозиторий Romagpt4444/verto-studio, ветка main, CNAME).
Текущее задание: TZ-VERTO-ROCKET.md — прочитать целиком перед любой работой. Оно главнее скиллов.
Материалы: `claude-code-brief/` — готовые тексты RU/EN (`content/*.json`), токены (`design/`), референсы, скиллы.

## Всегда
- Сначала изучи проект и существующий код. Не переписывай с нуля то, что работает, и не теряй функции.
- Работай в ветке `redesign/rocket`. В `main` не пушь и не сливай без явного «ок» владельца.
- После каждого изменения: сборка, консоль без ошибок, проверка 375 / 768 / 1440 px, только потом «готово» (скилл verification-before-completion).
- Не добавляй функции, которых нет в ТЗ. Отступления от ТЗ записывай в `docs/DECISIONS.md` с причиной.
- Тексты для сайта — только из `claude-code-brief/content/*.json` (= раздел 13 ТЗ). Не выдумывай цифры, цены, отзывы, обещания роста продаж.
- Демо-сайты в `projects/` не меняй.
- Никаких форм с персональными данными, аналитики и сторонних скриптов/CDN.
- Скиллы проекта лежат в `.claude/skills/`. Какой скилл на каком этапе — раздел 15 ТЗ.

## Команды
- `npm run dev` — разработка
- `npm run build` — сборка в `dist/`
- `npm run preview` — просмотр сборки
- `python3 scripts/site_qa.py` и `node scripts/browser_qa.cjs` — проверки (обновить под новую сборку в фазе 7)

## Стиль общения с владельцем
Коротко, по делу, по-русски. Отчёт после фазы: что сделано, скриншоты, что проверено, что осталось.

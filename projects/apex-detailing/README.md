# APEX Detailing — демонстрационный проект Verto Studio

Премиальный одностраничный сайт автодетейлинг-студии. Проект собран на чистых HTML, CSS и JavaScript без сборщика и лишних зависимостей.

## Запуск

Запустите корень репозитория через локальный HTTP-сервер и откройте
`/projects/apex-detailing/`. Не используйте `file://` для production-проверки.

## Файлы

- `index.html` — структура и контент сайта;
- `styles.css` — дизайн, анимации и адаптивная версия;
- `script.js` — мобильное меню и появление секций при прокрутке;
- `assets/images/` — локальные изображения проекта.

Контакты, адреса и описания внутри проекта являются демонстрационными. Основной
CTA ведёт в Telegram-бот Verto Studio; локальной формы отправки нет.

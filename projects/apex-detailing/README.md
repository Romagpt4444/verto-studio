# APEX Detailing — демонстрационный проект Verto Studio

Премиальный одностраничный сайт автодетейлинг-студии. Проект собран на чистых HTML, CSS и JavaScript без сборщика и лишних зависимостей.

## Запуск

Самый простой способ: открыть папку в VS Code, открыть `index.html` и нажать **Go Live**.

Также можно дважды нажать на `index.html`, но для полноценной локальной проверки лучше использовать Live Server.

## Файлы

- `index.html` — структура и контент сайта;
- `styles.css` — дизайн, анимации и адаптивная версия;
- `script.js` — меню, появление секций, параллакс, «До / После» и форма записи.

Контакты, адрес, цены и отзывы являются демонстрационными. Форма не отправляет данные.

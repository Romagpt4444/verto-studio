## 1. Что делаем и зачем

**Задача.** Переделать главную страницу vertostudio.ru из портфолио в **сайт-визитку**: человек за 10 секунд понимает, кто мы, что делаем и как с нами связаться. Портфолио остаётся, но работает как доказательство, а не как главный смысл.

**Для кого.** Владельцы малого и среднего бизнеса в России, которым нужен сайт, лендинг, интернет-магазин или Telegram-бот. Не дизайнеры и не программисты. Термины им ничего не говорят, поэтому тексты пишем обычными словами.

**Главное действие на сайте.** Написать нам в Telegram (@Verto_Studio). Всё остальное (WhatsApp, Instagram, канал) — запасные пути.

**Какое впечатление.** «Ребята делают живые, необычные сайты, с ними просто договориться». Сайт сам по себе — пример нашей работы: максимально анимированный и дизайнерский, но при этом быстрый и понятный.

**Сюжет.** Весь сайт — полёт ракеты Verto-1. Посетитель листает страницу, ракета взлетает со стартового стола, проходит атмосферу, сбрасывает ступени и выходит на орбиту, где ждёт кнопка «Обсудить в Telegram». Метафора простая: мы запускаем ваш проект.

### 1.1 Почему ракета (а не спорткар и не другое)

| Вариант | За | Против | Решение |
|---|---|---|---|
| **Ракета** | Метафора «запуск проекта» понятна всем. Вертикальный полёт совпадает с прокруткой вниз. Ступени ракеты = этапы и стек. В проекте уже есть ракетные изображения (`assets/rocket-sequence/`) для заглушек | Тема популярна, нужно сделать ракету своей, а не мультяшной | **Берём** |
| Спорткар | Скорость, драйв | Движение горизонтальное, плохо ложится на вертикальный скролл. Ассоциация с автосервисом (у нас кейс Master Tyres, будет путаница) | Нет |
| Бумажный самолётик | Лёгкость, «отправить сообщение» | Слишком мелкая метафора для студии | Нет |

Название ракеты на борту: **VERTO-1**. Латинское *verto* — «поворачиваю, направляю». На борту ракеты — логотип V.

## 3. Design Read и настройки

**Design Read:** сайт-визитка креативной веб-студии для владельцев бизнеса; язык — «тёмный космос + один сочный акцент + кинетическая типографика»; основа — Astro + собственный CSS на токенах + Three.js + GSAP ScrollTrigger + Lenis.

Настройки из `design-taste-frontend`:

| Шкала | Значение | Почему |
|---|---|---|
| `DESIGN_VARIANCE` | 8 | Агентский сайт, нужен характер, асимметрия |
| `MOTION_INTENSITY` | 8 | Требование владельца: «максимально анимированный». Не 10, потому что текст должен читаться |
| `VISUAL_DENSITY` | 3 | Визитка, много воздуха, по одной мысли на экран |

**Чего избегаем (анти-шаблоны):** фиолетово-синие ИИ-градиенты, центрированный hero поверх мутной сетки, три одинаковые карточки в ряд, стекло на всём подряд, неон, «геймерская» и «крипто» эстетика, бежево-латунная палитра, Inter по умолчанию, мультяшная ракета.

## 4. Цвет

Требование: яркий, сочный, но не режет глаза. Решение — **один акцент «Зажигание» (Ignition Orange)** на глубоком космическом тёмно-синем. Оранжевый — цвет пламени двигателя, поэтому он связан с сюжетом. Тёмно-синий фон продолжает прежний фирменный `#071426`, узнаваемость не теряется.

Правило: оранжевый занимает **не больше 5–8 % площади экрана**. Он только на главной кнопке, на активных состояниях, на пламени ракеты, на шкале высоты и на отдельных словах. Всё остальное — оттенки фона и светлый текст. Поэтому цвет сочный, но не утомляет.

### 4.1 Токены (файл `src/styles/tokens.css`)

```css
:root {
  /* Фон: космос */
  --space-950: #05070D;  /* основной фон страницы */
  --space-900: #0A0F1C;  /* приподнятые блоки */
  --space-800: #121A2B;  /* карточки, панели */
  --space-700: #1C2740;  /* линии, рамки */
  --space-600: #2A3654;  /* рамки при наведении */

  /* Текст: звёздный свет */
  --star-50:  #EEF1F6;   /* основной текст          17.8:1 на 950 */
  --star-300: #A6AFC0;   /* второстепенный текст      9.1:1 */
  --star-500: #7E889C;   /* подписи, мелочи           5.6:1 (на 800 — 4.9:1) */

  /* Акцент: зажигание */
  --ignition-300: #FFB38F; /* мягкое свечение, блики */
  --ignition-400: #FF8A55; /* hover                   8.6:1 на 950 */
  --ignition-500: #FF6B2C; /* основной акцент         7.1:1 на 950 */
  --ignition-600: #E5531A; /* нажатие */
  --ignition-glow: rgb(255 107 44 / 0.18);

  /* Семантика (использовать в компонентах только их) */
  --bg: var(--space-950);
  --bg-raised: var(--space-900);
  --surface: var(--space-800);
  --line: var(--space-700);
  --line-strong: var(--space-600);
  --text: var(--star-50);
  --text-dim: var(--star-300);
  --text-mute: var(--star-500);
  --accent: var(--ignition-500);
  --accent-hover: var(--ignition-400);
  --accent-press: var(--ignition-600);
  --on-accent: var(--space-950);  /* текст на оранжевой кнопке ТЁМНЫЙ: 7.1:1. Белый на оранжевом = 2.8:1 — запрещено */

```

Проверено расчётом WCAG: все пары текста ≥ 4.5:1. При любом изменении цвета перемерить по скиллу `better-colors` (раздел «Measure the rendered pair»).

### 4.2 Правила цвета
- Один акцент на всю страницу. Никаких синих, зелёных, фиолетовых кнопок «для разнообразия».
- Градиенты только из одного тона (оранжевый → прозрачный, тёмно-синий → чёрный), интерполяция `in oklch`.
- Тени тонировать в цвет фона, не чёрные.
- Звёзды и линии орбит — `--star-50` с прозрачностью 0.2–0.6.
- Если владелец захочет вернуть синий — меняется только блок «Акцент» в токенах, компоненты не трогаем.

- Цифры в счётчиках и процентах: `font-variant-numeric: tabular-nums`.
- Выделение слова в заголовке — тем же шрифтом другим цветом (`--accent`), не другим шрифтом.
- Скилл: `better-typography`.

## 8. Блоки подробно

Тексты всех блоков — в разделе 13. Здесь — вёрстка, поведение и анимация.

### 8.0 Прелоадер «Заправка»
- Показывается только при первом заходе за сессию (флаг в `sessionStorage`, обёрнутый в try/catch) и максимум 2.2 с. Если ресурсы готовы раньше — закрывается раньше, но не быстрее 0.9 с, чтобы анимация не мелькала.
- В центре — силуэт ракеты (SVG), снизу вверх заполняется оранжевым «топливом» синхронно с процентом. Подпись «Заправляем ракету» моноширинным шрифтом.
- Уход: силуэт уезжает вверх, экран раскрывается через `clip-path: inset()` от центра (ease-out `cubic-bezier(0.23,1,0.32,1)`, 700 мс).
- При `prefers-reduced-motion` прелоадера нет. Без JS прелоадера нет (контент виден сразу).
- Важно для LCP: hero-текст отрисован в HTML под прелоадером, прелоадер — оверлей, а не блокировка рендера.

### 8.1 Шапка
- Высота 64 px (десктоп 72), фиксированная, при скролле вниз прячется, при скролле вверх появляется (translateY, 250 мс).

## 9. Ракета Verto-1 (3D)

### 9.1 Модель
- **Строится процедурно в коде Three.js** (скилл `img2threejs`, референс — `assets/rocket-sequence/web/01-rocket-before-launch.jpg` по форме, но стилизовано). Готовые модели с маркетплейсов не брать (лицензии, вес, стиль).
- Форма: корпус — `LatheGeometry` по профилю (обтекатель, цилиндр, переходник), 4 стабилизатора, иллюминатор с логотипом V, кольца между ступенями. Ступени — отдельные `Group`: `stage1` (низ), `stage2`, `stage3`, `capsule` (верх) — чтобы подсвечивать и отделять.
- Материалы: корпус — светлый матовый металл (`MeshStandardMaterial`, color `#D9DEE7`, metalness 0.6, roughness 0.35); кольца и полосы — `--ignition-500`; стабилизаторы — `--space-700`; иллюминатор — тёмное стекло с бликом. На борту надпись «VERTO-1» (текстура canvas или геометрия).
- Стиль: чистый, «продуктовый», как дорогая игрушка-модель. Не мультяшный, не фотореализм.
- Полигоны: десктоп ≤ 40k треугольников, мобильный ≤ 15k (уменьшить сегменты lathe).

### 9.2 Сцена
- Один `WebGLRenderer`, `canvas` фиксирован на весь экран позади контента (`position: fixed; inset: 0; z-index: 0; pointer-events: none`, кроме области hero для клика — через raycast по событию на document).
- Свет: ключевой холодный сверху-слева, контровой оранжевый снизу (от пламени, интенсивность растёт при работе двигателя), слабый `HemisphereLight`.
- Фон сцены прозрачный, космос рисуется CSS-градиентом (`--space-950` → `#000`) + слой звёзд в Three.js (`Points`, 1500 точек десктоп / 600 мобильный, мерцание в шейдере).
- Пламя: конус + шейдер шума (оранжевый → белый в центре), аддитивное смешивание, длина зависит от «тяги» 0–1.
- Пар/дым на старте: 20–40 спрайтов с мягкой текстурой, рассеиваются.
- Линии орбит: 2–3 тонких эллипса вокруг ракеты (как кольца вокруг банки на референсе), медленно вращаются.
- Постобработка: только лёгкий bloom на пламени для десктопа с хорошим GPU. На мобильных — без постобработки.

### 9.3 Хореография по прокрутке
Один мастер-таймлайн GSAP, `scrub: 1`, привязан к прогрессу всей страницы. Позиции — относительные по якорям блоков (`start: 'top center'` у каждого блока), не магические проценты.

- Движение мыши (десктоп): ракета слегка поворачивается к курсору (±6°, пружина, `quickTo`).
- Плавность значений — `gsap.quickTo`/lerp в `requestAnimationFrame`, без `setState`-подобных пересчётов.

### 9.4 Производительность и запасные варианты
- Три.js и сцена грузятся **после** первой отрисовки: динамический `import()` в `requestIdleCallback` (или через 300 мс после `load`). До готовности на месте ракеты — постер (рендер ракеты в WebP/AVIF, сделать скриншотом из готовой сцены, ≤ 60 КБ). Смена постер → 3D через перекрёстное проявление 400 мс.
- Бюджет 3D-кода: ≤ 250 КБ gzip (Three.js с tree-shaking + сцена).
- `renderer.setPixelRatio(Math.min(devicePixelRatio, 1.75))` десктоп, `1.5` мобильный. Адаптивное качество (`quality.ts`): если средний кадр > 22 мс за 2 с — отключить bloom, уменьшить звёзды и DPR.
- Рендер останавливается, когда вкладка скрыта (`visibilitychange`), и рендерится по требованию, когда ничего не двигается.
- **Нет WebGL** или `navigator.connection.saveData` → статичный постер + CSS-анимации, сайт полностью работает.
- **`prefers-reduced-motion: reduce`** → ракета статична (постер), нет прелоадера, нет Lenis, нет пина и горизонтальной ленты (обычный список), лента-марки стоит, появления блоков — только проявление 200 мс без сдвига. Кнопка «Остановить анимацию» в подвале переключает этот режим вручную (сохранить в `localStorage` с try/catch).
- Освобождать геометрии/материалы при уходе со страницы (на будущее для View Transitions).

### 10.1 Токены (`src/styles/motion.css`)
```css

  --dur-reveal: 700ms;  /* появление блоков (маркетинговые анимации могут быть длиннее) */
  --stagger: 60ms;
}
```
В GSAP использовать те же кривые (`CustomEase` или `"expo.out"` как ближайшая), не придумывать новые.

### 10.2 Правила (нарушение = блокер)
- Анимировать только `transform`, `opacity`, `clip-path`, `filter`. Не анимировать `width/height/top/left/margin/padding`.
- Никогда `transition: all`. Никогда `scale(0)` на входе — `scale(0.95)` + `opacity: 0`. Никогда `ease-in` на интерфейсе.
- Hover-эффекты только в `@media (hover: hover) and (pointer: fine)`.
- Элементы появляются лесенкой (30–80 мс), не все сразу.
- Интерфейс (кнопки, вкладки, меню) ≤ 300 мс. Длинные — только сюжетные.
- Каждая анимация имеет вариант для `prefers-reduced-motion` (мягче, не «ноль»: оставить проявление).
- Появление блоков: один `IntersectionObserver`/`ScrollTrigger.batch`, срабатывает один раз.
- Текст никогда не перекрывается ракетой так, чтобы мешать чтению: у текстовых блоков `z-index` выше canvas, при необходимости — подложка `--bg` 0.6 с blur.

### 10.3 Список микро-взаимодействий
1. Магнитная главная кнопка (десктоп).
2. Кнопки: `:active` → `scale(0.97)` за 120 мс.
3. Ссылки: подчёркивание растёт слева направо.
4. Курсор (десктоп, опционально): маленькая точка `--accent` + кольцо, кольцо увеличивается над ссылками и над ракетой («Нажмите»). Нативный курсор не скрывать полностью (доступность), только дополнить.
5. Заголовки блоков: слова выезжают из-под маски лесенкой.
6. Счётчики: 0 → число, 900 мс.
7. Фильтр: «таблетка» переезжает.
8. Карточки: подъём + пятно света + повтор стикера.
9. Бегущая строка: скорость от скролла.
10. Шкала высоты: заливка и цифры.

## 16. SEO, доступность, безопасность, скорость

**SEO**
- Уникальные title/description для RU и EN (раздел 13), `canonical`, `hreflang`, Open Graph и Twitter Card. Новая OG-картинка 1200×630: ракета + «VERTO STUDIO» (рендер из сцены), RU и EN версии.
- JSON-LD `Organization` (имя, URL, логотип, `sameAs`: Telegram, канал) — перенести и обновить.
- `sitemap.xml` (Astro sitemap) с RU и EN, `robots.txt` с ссылкой на sitemap, `llms.txt` с кратким описанием студии и ссылками.
- Один `<h1>` на страницу, логичные `h2` у блоков.
- Весь текст в HTML (не в canvas), чтобы поисковики и ИИ-поиск его видели.

**Доступность (WCAG 2.1 AA)**
- Контраст по разделу 4. Фокус виден везде: обводка 2 px `--accent` со смещением 3 px.
- Вся навигация с клавиатуры, включая фильтр, язык, FAQ, шкалу высоты. Ссылка «Перейти к содержанию».
- Ракета — декоративный `canvas` с `aria-hidden="true"`; интерактив «прогрев» дублирован кнопкой с подписью для скринридера или помечен как декоративный.
- `prefers-reduced-motion` и ручная кнопка остановки анимации (раздел 9.4). Ничего не мигает чаще 3 раз в секунду (тряска — движение, не вспышки).
- Внешние ссылки: `target="_blank" rel="noopener noreferrer"` и пометка «↗».

**Безопасность**
- CSP в `<meta>` (как сейчас): `default-src 'self'; script-src 'self'` (+ хэши inline-скриптов, если Astro их создаёт; лучше вынести всё во внешние файлы); `img-src 'self' data:`; `connect-src 'self'` (для загрузки JSON стикеров); `frame-src 'none'`; `object-src 'none'`; `base-uri 'self'`; `form-action 'none'`. Проверить, что Three.js, GSAP и lottie_light работают без `unsafe-eval`.
- `referrer`: `strict-origin-when-cross-origin`. Никаких сторонних скриптов, трекеров, CDN.

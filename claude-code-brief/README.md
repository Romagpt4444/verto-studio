# Пакет для Claude Code: сайт-визитка Verto Studio «Ракета Verto-1»

## Как запустить
1. Папка `claude-code-brief/` должна лежать в корне проекта `Verto-Studio-GLOBAL-UPDATE`. Если вы получили архив — распакуйте его туда.
2. Положите `TZ-VERTO-ROCKET.md` и `CLAUDE.md` в корень проекта (там они уже лежат).
3. Откройте проект в Claude Code и вставьте стартовый промпт из раздела 0 ТЗ.

## Что внутри
- `TZ-VERTO-ROCKET.md` — полное ТЗ: концепция, цвет, шрифты, стек, все блоки, 3D-ракета, анимации, стикеры, RU/EN, SEO, этапы, критерии готовности.
- `CLAUDE.md` — постоянные правила для агента.
- `content/ru.json`, `content/en.json` — готовые тексты сайта (ключи совпадают).
- `design/tokens.css`, `design/motion.css` — токены цвета и движения.
- `references/` — скриншоты референсов.
- `skills/` — 30 отобранных скиллов (из папки «SGX-скиллы» + humanizer-ru из «Скиллы»).
